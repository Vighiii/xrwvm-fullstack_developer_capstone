# xrwvm-fullstack_developer_capstone

## Project Name
Dealership Review Web Application

## Repository Name
xrwvm-fullstack_developer_capstone

## Project Description
This project is a full-stack dealership review web application developed using Django, React, Docker, Kubernetes, and MongoDB. The application allows users to view dealerships, read customer reviews, and post reviews after authentication.

## Features
- User Authentication (Login/Register)
- View Dealerships
- Dealer Review System
- React Frontend Integration with Django
- REST API Backend
- MongoDB Database Support
- Docker and Kubernetes Deployment

## Technologies Used
- Django
- React.js
- Node.js
- MongoDB
- Docker
- Kubernetes
- IBM Cloud Code Engine
